Вам необхідно взявши за основу файли з урока - todo list, написати свою реалізацію туду ліста.

Ви можете перевикористовувати верстку з хтмл файлу, але увесь JS потрібно писати самостійно.

**Писати через MVC та Функції конструктори обов'язково**

Дз треба здавати наступним чином:
1. Намалювати діаграму роботи перед написанням коду
2. Написати код (алгоритм і приклади нижче)

Що необхідно зробити -
1. Зібрати дані з форми
2. Перевірити дані
3. На базі зібраних даних згенерувати елемент для відображення на сторінці
4. Вставити елемент на сторінку при сабміті форми
5. Очистити форму
6. Також, необхідно зберігати масив об'єктів туду айтемів в localStorage, після перезаванатаження сторінки (якщо дані є в localStorage) відрендерити їх там де вони були до завантаження.
