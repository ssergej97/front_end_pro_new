📌 Опис:
Реалізуйте інтерфейс для управління категоріями (наприклад, для блогу чи магазину). Категорії можуть бути вкладеними (мають підкатегорії). Кожну категорію можна:
Створити (на рівні root або як підкатегорію)
Переглянути (вкладену структуру дерева)
Редагувати назву
Видалити (разом з усіма підкатегоріями)
Збереження стану у localStorage

🎯 Функціональні вимоги:
1. Read (побудова дерева)
   Показати дерево категорій (вкладене UL → LI)

При кліку на назву — відкривати/закривати вкладені категорії

2. Create
   Кнопка "➕ Додати категорію" — додає нову root-категорію

Кнопка "➕ Додати підкатегорію" біля кожної категорії — додає вкладену

3. Update
   Біля кожної категорії — кнопка ✏️ для редагування назви (input + confirm)

4. Delete
   Біля кожної категорії — кнопка 🗑 для видалення (з підтвердженням), рекурсивно видаляє все вкладене

🛠️ Технічні обмеження:

Тільки чистий JS + HTML + CSS
Можна використовувати data- атрибути* для ідентифікації вузлів
Дерево зберігається в оперативній пам’яті (масив об'єктів)
